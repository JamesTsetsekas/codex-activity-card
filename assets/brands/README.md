# Codex mark

`codex.svg` is copied without changes from the [AGENTS.md project's Codex asset](https://github.com/agentsmd/agents.md/blob/main/public/logos/codex.svg), retrieved November 2, 2026. The former `openai/agents.md` repository redirects to that project. This is a traceable upstream asset, not a claim that it is the current OpenAI press-kit release.

The renderer preserves the supplied geometry and black color, and places the mark on a light backing in either theme. Use `--no-logo` for a text-only card.
